# ❄️ Snowflake Connectivity Options
## 🔹 Web Interface

### ✅ Snowsight
- Snowflake's modern WebUI for interactive data exploration.
- Supports dashboards, worksheets, visualizations, and administrative tasks.

---

## 🔹 Command Line Tool

### ✅ SnowSQL
- CLI for executing SQL queries, managing sessions, and automating tasks.
- Supports scripting and integration with CI/CD pipelines.

---

## 🔹 Drivers

Snowflake provides native drivers for various programming languages:

- Go
- JDBC
- .NET
- Node.js
- ODBC
- PHP PDO

---

## 🔹 Connectors

Snowflake supports connectors for popular data platforms:

- Python Connector
- Kafka Connector
- Spark Connector

---
